## Plan A — Destruabar runtimes retirando el encuadre F03 deprecado

**Método:** change OpenSpec nuevo `retire-f03-runtime-gate` (rama `fix/retire-f03-runtime-gate`).
**Por qué ahora:** el botón "Continuar" nunca arranca porque ningún runtime coincide con la versión exacta del fixture F03 (Claude 2.1.132≠2.1.206, Codex 0.144.4≠0.143.0). El encuadre F03/Fases está deprecado desde el cleanup de scaffold, pero sus fixtures y el gate de versión sobrevivieron. Se retira completo.

### Decisión de diseño
- **El gate de versión se quita** (`runtime-session-hub.ts:145`): un runtime es lanzable si el adaptador lo declara y el binario está instalado. Ya no exige `evidenceStatus === 'verified'`.
- **`evidenceStatus` queda como metadato informativo** (no bloqueante). Las capabilities cuyos `evidenceRefs` apuntaban a fixtures borrados pasan a `pending_fixture` — no se afirma "verified" sin evidencia que lo respalde (invariante de honestidad). El arranque se destraba igual.
- **No se inventa evidencia nueva** para reemplazar los fixtures. "Solo OpenSpec" es el método; no se monta otro sistema de verificación de runtime.
